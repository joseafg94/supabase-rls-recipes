# Phase 00 — Project Audit and Context

## Objective

Confirm repository state, current official platform behavior, planning consistency, and decisions required before implementation.

## Allowed scope

Read all root/docs/templates/checklists files; inspect Git history/status; check installed Supabase/PostgreSQL tooling and official changelog/docs; record findings and decisions in planning documents.

## Forbidden scope

No recipe SQL, Supabase initialization, dependencies, hosted project access, migrations, CI, or frontend.

## Expected files

Updates only to `PROJECT_PROFILE.md`, `docs/PROJECT_CONTEXT.md`, `docs/ARCHITECTURE.md`, or a new concise audit record if evidence warrants it.

## Verification

Resolve internal links, compare recipe/phase lists, and cite current primary sources for version-sensitive claims.

## Completion criteria

Tool availability, open decisions, risks, contradictions, and the exact phase 01 inputs are documented.

## Stop condition

Stop after the audit report; do not initialize or implement.

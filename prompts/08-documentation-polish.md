# Phase 08 — Documentation Polish

## Objective

Make documentation precise, internally consistent, navigable, and faithful to verified behavior.

## Allowed scope

Edit prose, tables, links, reproduction commands, recipe catalogs, limitations, and attribution; add no behavior.

## Forbidden scope

No schema/policy/test behavior changes, dependencies, visual site, marketing claims, or release publication.

## Expected files

README and documentation/recipe README updates only, unless a link checker configuration is strictly needed.

## Verification

Check links, commands, file names, phase/recipe lists, terminology, matrices against tests, and security disclaimers. Re-run tests if wording asserts behavior.

## Completion criteria

A reader can reproduce each recipe and trace every security claim to a test or explicit assumption.

## Stop condition

Stop before versioning or publishing a release.
